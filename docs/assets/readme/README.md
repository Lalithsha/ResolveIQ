# README visual assets

`hero.svg` is a static vector illustration authored for the README. It summarizes the implemented support workflow and is not a product screenshot.

The five PNGs are unmodified 1920×1080 browser captures from the October 5, 2026 light-mode demo. All names, tickets, transactions and incident counts are fictional local fixtures. Their source was `brag-output-2026-10-05-074045/captures/`; the original captures and MP4 are preserved locally.

| Asset | Captured state |
|---|---|
| `support-workspace.png` | Selected ticket, grounded article citation and response approval boundary |
| `refund-approval.png` | $40 simulated refund proposal approved; execution remains a separate control |
| `incident-radar.png` | Customer update published following Team Lead drafting and Administrator approval |
| `evidence-lab.png` | Consented log artifact ready; default preview redacts the email address |
| `knowledge-release.png` | Prepared six-customer cohort sanitized, evaluated and released by a Knowledge Manager |

UI confidence, incident counts and evaluation values in these screenshots describe the local configured demo. They are not measured production accuracy, adoption or business-impact figures. The full demonstration is available through the stable GitHub attachment URL in the root README.
